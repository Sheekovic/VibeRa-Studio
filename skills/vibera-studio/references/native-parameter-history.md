# Supported native scalar edits and history

Use `vibera_plugin action=list`, then `parameters` with exact plugin/instance to discover native uint32 parameter IDs, current catalogue generation and normalized values. ID0 is valid. `action=set` requires exact instance, generation, parameter and finite normalized value0..1; an optional current Project revision can additionally guard admission.

Set returns a pending operation. Poll `vibera_plugin action=job` with that operation until terminal. `nativeDispatched` means the real worker request was sent; `nativeApplied` means a successful actual ACK or native completed gesture was observed. `historyCommitted`/`undoable` require a fresh acknowledged native state capture and one canonical history edge. A failed job may have an applied native edit with unavailable history; do not retry blindly or claim rollback. Cancellation can only stop undispatched work. Dispatched control/capture remains owned and reports tooLate until its actual outcome drains.

The shared Controls slider uses the same service and coalesces one drag into one history edge after the final ACK. Completed supported native VST3 parameter gestures use the sole Host event drain, with source/schema/epoch/loss checks. State exposes the last `nativeScalarOperation` for its retained job. Arbitrary native widgets, programs, hidden provider state reversal, schema/layout changes and unbalanced/lost events are unsupported by scalar reconstruction. An actual native edit remains dirty when history cannot be constructed.

First unbound edits stay unbound. Existing native manual fallback is updated in the same canonical action; linked automation still owns its sounding curve. During a genuine active MIDI take, manual UI/MCP scalar writes use the same physical ACK service with `completionScope=nativeScalarAckDuringRecording`, `recordingWriteOnly=true`, `historyCommitted=false` and `historyUnavailableReason=recordingCaptureProtected`. No state capture or parameter history is created; existing automation/manual fallback remains unchanged. This preserves existing live native control behavior without interrupting capture. Stop can commit the take while an already dispatched ACK drains; further queued writes refuse a changed capture session. Armed-only, retained takes and incompatible structural/native state operations still refuse scalar history capture without discarding their data. Save/export capture current native state after capture settles.

Undo/Redo use the existing bounded full-projection restoration and can interrupt audio briefly. Native editors must be closed before structural restoration when required by its source admission. Poll the returned chain/history operation until actual activation completes. Initial no-device history may complete only document/deferred preparation; it does not establish an old control-only Host's native scalar restoration or audible activation. Device loss/recovery and postpublication failure remain explicit. Save/export continue to capture fresh native state.

Focused source acceptance now passes original SDK Controls/MCP/native gesture history and actual installed Analog Lab V write/Undo/Redo/fresh Save/reopen, including fixed post-recovery zero continuing loss and unchanged outer callback deadlines.
