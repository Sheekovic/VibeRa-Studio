## Identity and metadata

Catalogue entries retain the unsigned VST3 ParamID, including zero, separately from JUCE display order and controller ordinal. Entries carry native flags, units, step count, default/current normalized values and original plugin names/labels. An exclusive bounded mailbox publishes complete snapshots (8192 parameters maximum). Invalid identity/steps, duplicate IDs or oversized metadata fail explicitly. Invalid current/default values carry explicit availability flags and zero placeholders; unavailable controls/defaults remain disabled. This preserves Analog Lab's internal MIDI helpers with -1 defaults without inventing usable values. Blank provider labels are retained in metadata; UI supplies an original fallback label. Generation changes invalidate old manual requests. MVibrato's startup refresh is explicitly refused and retried once against fresh metadata in qualification. Changing native IDs in-place is rejected; complete dynamic schema reconstruction remains pending.

Manual requests use a separate acknowledgement mailbox. Busy, stale, unavailable, hidden/read-only and malformed controls are explicit outcomes. The message thread performs editor/controller calls and gestures; no plugin library is loaded in the DAW process. Acknowledgements read back the native controller's normalized value, including quantization.

## Stopped-state persistence

State capture pauses audio packets and performs a parameter-only call on the existing isolated DSP thread, with zero audio buffers/samples and no host cursor advancement, as permitted by the [VST3 API](https://steinbergmedia.github.io/vst3_dev_portal/pages/Technical%2BDocumentation/API%2BDocumentation/Index.html). A revision/ticket handshake completes before control-thread state serialization; concurrent new edits cause another bounded flush attempt.

These values are initialized after preparation and rearmed for the next real audio packet. Unavailable, malformed or unknown saved targets fail explicitly; legacy states without the host snapshot remain supported. No synthesized audio frame or transport advancement is used. ## Prepared delivery

Audio packets carry at most512 native ID/frame/value events. The main callback validates finite normalized values, bounded count, sorted offsets and packet boundaries before sending; partial callback chunks retain packet-relative offsets. Queue saturation, late discarded packets and malformed/unknown events count as rejected delivery. There is no live wait, allocation or UI call in the added main callback path.

The pinned JUCE host has a small original local extension that retains native flags, validates prepared timed events and merges cached offset-zero, mapped MIDI and explicit host points into sorted/coalesced native queues. A later writer replaces a point at the same sample; explicit points take precedence at equal offsets. Final merged values for timed targets are echoed through the existing control-thread dispatcher. Cached manual writes are not overwritten. Queue node storage is prepared outside processing. This does not establish allocation/lock freedom for the entire upstream wrapper or third-party DSP.
