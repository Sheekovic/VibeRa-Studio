## Read the status correctly

| Status | Meaning |
| --- | --- |
| Qualified preview | Packaged executable and source have matching, recorded verification for the stated subset. |
| Implemented / partial | Working implementation exists, with evidence for specific scenarios; the whole feature family is not accepted. |
| In progress | Changes are being implemented or diagnosed; do not assume they are in the latest package. |
| Planned | Required product work, without a qualified implementation. |
| Pending user check | Engineering can continue, but listening, hardware or familiarity acceptance needs a recorded user result. |

No percentage is assigned: counting buttons or source files would give a misleading measure of a DAW's completeness. Update feature rows when acceptance evidence changes, not merely when code is added.
