# Typing keyboard to piano (0.0.9)

Enable Typing keys in the transport area or Ctrl+T. Plain mapped letter/number/punctuation keys play the selected Channel; when enabled these keys take precedence over plain-letter editing shortcuts. Modifier shortcuts, editor switching, Space and Esc retain their command path. Text editors do not play notes. Turn typing off to use plain-letter editing tools again. Existing custom shortcut profiles are preserved; the midi.typing command can be rebound.

Chromatic layout: Z/S/X/D/C/V/G/B/H/N/J/M/comma/L/period/semicolon/slash from the chosen root; Q/2/W/3/E/R/5/T/6/Y/7/U/I/9/O/0/P/left bracket/equals/right bracket one octave above. Default root is MIDI 60 and velocity 100. Right-click Typing keys chooses C roots/velocity. Choices persist in local typing-keyboard.json in normal application use. Non-US physical layouts, alternate scale/chord maps, channel-root-aware transposition and arbitrary performance-key remapping remain open. Plain-key priority is intentional FL-style behavior; command remapping remains separate from performance mapping.

Repeating key-down never retriggers a held key. Overlapping physical keys mapped to the same pitch use reference counts. Note-off retains the pitch from key-down even if root changes. Disabling input, target changes and application focus loss release held typing notes. UI key-state events and a bounded message-thread fallback poll release keys; note-off latency from that fallback is not hardware-qualified. Text/modal/other windows also release keys. Native plugin editors live in another process; typing input from those editor windows is not supported yet.

## Audio and recording separation

Typing input has a separate single-producer lane and capture queue from physical MIDI. Prepared per-source voice banks handle built-ins. Hosted instruments merge live input note ownership so releasing one source does not cut another holding the same channel/key, and overlapping sources do not emit duplicate note-ons. The audio clock is published for both sources; no callback waits, new allocation, file I/O or UI calls are added by this path. Structural preparation/resource reclamation remains outside the callback. This is not a complete upstream real-time audit or a guarantee about all MIDI sustain/voice semantics of all plugins.

Rec > Play > performance > Stop uses the existing take command and one undo. Captured note keys include source identity, so device/target epochs and overlapping keyboard/device notes do not invalidate each other. Existing count-in and live previews remain. Recording stores notes/velocity only; score logging, CC recording and MIDI interchange remain future work.
